1. **必须用 `/usr/bin/python3`**（有 pyopencl）；`/usr/local/bin/python3` 是 numpy 2.5 但**无 pyopencl**。
2. 本机 numpy **1.26.4**：`np.bitwise_count`／`np.trapezoid` 会炸 ——
   `z0_genesis.py`、`l2_capacity.py`、`z0_mass_spectrum.py`、`H3_check.py`、`verify/d231,d234,d235,d238` 目前**跑不起来**（待修）。
3. 整数重数的**精确性只在 int64 段**（3–4 代），之后必须转 float64（`Z0_CORE §8.3` 边界 1）。
4. **别信"停在某个代数"的结论**：§22 的"真畴"就是 40 代假象；判"冻结"必须看**长程斜率**（§26 口径）。
5. `simulations/zero_sum_*.py` 要在 `lh/` 根下跑（`cd lh && python3 simulations/...`）。
6. 层纪律（`R50`）：**每个量带层指标**；本轮最易犯的两处＝把 L1 记录当 L2 活跃量、
   把 $K_{\rm cap}$（L0/L2）与 $K_\omega=-\log\omega$（$\mathcal R$）混用。
