# 自持环：闭合 → 记录 → 毁灭/重播种 → 回灌

> **等级：$r^*=1$ 的临界性是【精确】（计数论证）；其余全部【数值证据】。**
> 机器：[`z0_loop.py`](z0_loop.py)｜数据 `results/z0_loop.json`｜用时 7.1 s

本文补的是用户图景里**唯一真正缺的那一环**：到本轮为止所有模拟都是**单向枚举**
（L0 → L1 只写不回灌），枚举完就结束，世界不会自己接着活。这里把环闭上。

## §1 环的定义（唯一的外加量是重播种强度 $r$）

```
        ┌──────────────── 回灌（只读保留的记录） ────────────────┐
        ↓                                                       │
   活动层 E（走者集合，各带 (起点 u, 当前位置 v)）                  │
        │ 每步：走一条边（保守读法：每条走者正好走一条）             │
        ↓                                                       │
   v == u ？ ── 否 ──→ 继续走                                     │
        │ 是（**闭合事件** Σw=0）                                 │
        ↓                                                       │
   写记录（远足长度）→ 毁灭（移除）→ **重播种 r 条** ──────────────┘
```

$r$ 的地位**不是自由的**，它可以被判定：

$$
\text{每条闭合移除 }1\text{ 条、重播 }r\text{ 条}
\quad\Longrightarrow\quad
\boxed{\ r^*=1\ \text{是精确临界点}\ }
$$

## §5 这个环证明了什么、没证明什么

**证明了**

1. **自持不需要调参**：Z0① 字面读法 $r=1$ 是**精确**临界点，活动量守恒（$A(t)$ 恒为常数，30 组运行无一例外）。
2. **稳态是良定义的**：远足长度分布同时满足 Kac 引理与 1D 精确首返律。
3. **记录层给出原生时间刻度**：闭合率 = 系统自己的时钟。

**没证明（诚实登记）**

| # | 缺口 | 说明 |
|--:|:--|:--|
| 1 | **保守读法是选择，不是导出** | $r=1$ 来自"每条走者每步走一条边"（L2-a 保守窗）。Z2 的全分支读法给 $r=\deg v$，落在爆炸相。**"选哪一半"本身没有从 Z0 导出** |
| 2 | **走者之间没有相互作用** | 环里的走者互不相见；相互作用只在**记录/碰撞分析**里进来（远足落到同一顶点）。要真相互作用，需要把整数重数合并**回灌进动力学**，本轮没做 |
| 3 | 毁灭是**逐走者**的，不是 D222 的区域寿命 $\tau_i$ | `D222` 的"局部寿命到达时全层清空"未实现；语料自己登记 `R-Z-LAYER-TIME-SUBLEVEL-GAP`（亚层从哪来是第 1 号开放问题） |
| 4 | 稳态里没有粒子、没有分域、没有维数选择 | $\rho(L)$ 无极点；区域数恒为 1；维数仍继承 $\Gamma$ |

**下一步（如果要把相互作用接进环）**：把"同一顶点被多条走者踩到 ⇒ 重数合并 ⇒ 改写该点的重播种率"作为反馈项加进 §1 的环，
即 $\;r_v = r_0\cdot f(\text{该点的整数重数})\;$。那时的相图会不会出现**新吸引子**（比如自组织临界），
就是下一个可判定问题。
