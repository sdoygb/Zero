## §0 嫁接协议（本总账的判据）

$$
\boxed{\ \textbf{一个数只有同时满足下列三条，才算"从 Zero 底座长出来的"}\ }
$$

| # | 判据 | 不满足时登记为 |
|--:|:--|:--|
| **J1** | **可独立复算**（不看原脚本也能得同一个数） | 【不可复现】 |
| **J2** | **输入全部是 Zero／框架结构量**（不是实验反解） | 【一致性检验】 |
| **J3** | **有机制**（为什么是这个形式，而不是数值巧合） | 【数值巧合（待机制）】 |

$$
\Longrightarrow\quad \textbf{判决分四档：}\quad
\underbrace{\text{【导出】}}_{J1+J2+J3}\ \
\underbrace{\text{【条件】}}_{J1+J2,\ \text{缺}J3}\ \
\underbrace{\text{【一致性检验】}}_{J1,\ \text{缺}J2}\ \
\underbrace{\text{【巧合/错误】}}_{J1\ \text{也缺}}
$$

### §1.4 ★ 嫁接判决：**【一致性检验】**，不是【导出】

$$
\boxed{\ J1\ ✅\ \text{可复现};\qquad J2\ ❌\ \textbf{输入是实验反解};\qquad J3\ ❌\ \textbf{机制缺}\ }
$$

**$J2$ 为何不合格（这是最关键的一条）**：

| 输入 | 性质 |
|:--|:--|
| $\alpha_s(M_Z)=0.1179$ | **实验** |
| $1/\alpha_{\rm em}(M_Z)=127.95$ | **实验** |
| $1/\alpha_Y(M_Z)=98.3654$ | **实验** |
| $\Delta\alpha=0.0663$ | **实验／标准物理** |
| $b_2,b_Y$（SM 一圈 $\beta$） | 标准物理（条件于 SM 场内容） |
| $R=\sqrt{5/3}$ | **框架** ✅（唯一的框架输入） |

$$\Longrightarrow\qquad
\boxed{\ \textbf{"一个框架数 }R\textbf{ 拟两个观测" ⟹ 每观测 ~3\% 的巧合概率}\ }
$$

**文件自己在 §F 的检查表里承认**：「`Q244`：$1/\alpha_X$ 穷举 300+ 无命中 ✗ ⟹ ✅ 本步**不碰** $1/\alpha_X$（**它仍是输入**）」

**本总账的定性（比文件更严）**：$1/\alpha_X$ 既然是实验反解，那么整条链的"对上"就**主要是 RG 跑的恒等式**，
$R=\sqrt{5/3}$ 的贡献是**把 $21\%$ 的偏差压到 $10^{-5}$** —— 这是**有信息的**（不是恒等式），
但它是**一个数拟合两个观测**，按 §0 的判据只能是【一致性检验】。

\qquad\begin{cases}A_{\rm 轻}=\sqrt2&(\text{Koide 几何版 }2\cos 45^\circ)\\ A_\nu=\sqrt{\Lambda/k_0}=\sqrt{3/2}&(k_0=2,\Lambda=3)\end{cases}
$$

### §2.2 ★ 中心检验：中微子的 $R$ 是不是**独立拟合**？

**答：不是。它从同一个 $A$ 精确导出**（本机器独立复算，差 $5.8\times10^{-16}$）：

$$
m_1=0\ 	ext{饱和}\ \Longrightarrow\ \cos x=-\tfrac1A,\ \sin x=+\sqrt{1-\tfrac1{A^2}}=\tfrac1{\sqrt3}
\ \Longrightarrow\ \boxed{\ R=\frac{m_2}{m_3}=\Bigl(\frac{7-2\sqrt6}{5}\Bigr)^2=\frac{73-28\sqrt6}{25}\ }
$$

> ★ **本文件新得的精确闭式**：振幅比 $=\dfrac{7-2\sqrt6}{5}=0.420204$，**平方**即质量比。
> （原文件只给 $R=(73-28\sqrt6)/25$，没有代数闭式；本文件补上。）
