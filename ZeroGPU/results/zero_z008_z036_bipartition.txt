§1 两个不同的代数（这是全部关键）
================================================================================================
  单个代数  𝒜_L = ⊕_{h=1}^{H} M_2(ℂ)，H = L/2 = 2
    dim = 4H = 8；**每块 n_i = 2**
  复合代数  𝒜_L ⊗ 𝒜_L
    dim = (4H)² = 64；**块 = M_2 ⊗ M_2 = M_4**
  [PASS] 复合代数维数 = (4H)² = 16H²（Z008 定理 1(a)） dim = 64

§2 Z036 定理 27 的障碍：单式嵌入的维数条件 m | n
================================================================================================
  要 M_2⊗M_2 ≅ M_4 单式嵌入 𝒜_L = ⊕_h M_2，由前件 B 需存在块使 m | n：
    需要 4 | 2  —— **假**
  故每块 n_i = 2 装不下 M_4 ⟹ **𝒜_L 内最多一个 M_2 拷贝**（定理 27）
  ⟹ 不存在「量子位＋量子位」双分划 ⟹ Bell 实验退化，|S| ≤ 2（Z036 §5.2）
  [PASS] 维数障碍：4 ∤ 2 ⟹ M_4 不能嵌入 ⊕M_2 ⟹ 无双分划 需 4|2，为假；n_i=2 < 4

  但 M_4 在 𝒜_L⊗𝒜_L 里【是直和项本身】，不需要嵌入：
    (⊕_h M_2) ⊗ (⊕_{h'} M_2) = ⊕_{h,h'} (M_2⊗M_2) = ⊕_{h,h'} M_4
    块数 = H² = 4，每块 4×4，总维数 = 4 × 16 = 64 ✓
  [PASS] 𝒜_L⊗𝒜_L 的块是 M_4（M_2⊗M_2），故 CHSH 可在此表述 H²·16 = 64

§3 ★ 更强的限制（Z008 定理 1(d)）：中心态 ⊗ 中心态 = 可分离
================================================================================================
  定理 1(d)：若 ρ = ⊕_h (w_h/2)I_2（中心态），则
    ρ⊗ρ = ⊕_{h,h'} (w_h w_{h'}/4)(I_2⊗I_2)
  每项是**乘积态**、系数非负且和为 1 ⟹ **ρ⊗ρ 可分离**
  ⟹ **即使在复合代数里，中心态也给不出 CHSH > 2**
  ⟹ **要 CHSH > 2，ρ_V 必须【非中心】**

  这与 Z027 命题 3 同源：
    ρ 非中心 ⟺ 存在块使两支**不等权** ⟺ 权重 ι-破缺

  ⟹ **CHSH 违反与非中心态是同一件事的两面。**

  数值核验（用 Z008 定理 16 的 rho_V 构造）：
    中心态 ⊕_h(w_h/2)I_2 : S = 0.000000（应 ≤ 2）
    rho_V, V=0            : S = 2.000000（应 = 2）
    rho_V, V=0.5          : S = 2.236068（应 = 2√1.25 = 2.236068）
    rho_V, V=1            : S = 2.828427（应 = 2√2 = 2.828427）
    公式核对：S = 2√(1+V²) 在 V=0,0.5,1 上 -> 2.000000, 2.236068, 2.828427
  [PASS] 中心态 S ≤ 2（即使放在复合代数里也退化，定理 1d） S = 0.000000
  [PASS] rho_V V=0 给 S = 2（可分离边界，Z008 定理 16） S = 2.000000
  [PASS] rho_V V=0.5 给 S = 2√1.25（公式 S=2√(1+V²) 逐点对） S = 2.236068
  [PASS] rho_V V=1 给 S = 2√2（Tsirelson 界，Z008 定理 16） S = 2.828427

  ★ 关键：rho_V 落在 𝒜_L⊗𝒜_L 的【一个 M_4 块】里，不在 𝒜_L 里：
    𝒜_L⊗𝒜_L = ⊕_{h,h'} M_2⊗M_2 = ⊕_{h,h'} M_4（H² = 4 块，每块 4×4）
    一个 M_4 块【就是】M_2⊗M_2 ⟹ 该块内可写 A⊗I 与 I⊗B
    ⟹ CHSH 的两个观测者是【同一条 M_4 块里的两个张量因子】，
       不是【同一个 𝒜_L 里的两个元素】
  [PASS] rho_V 的支撑与 M_4 块结构相符（4×4，落在单个块内） shape = (4, 4)

  非中心性核验（「中心」= 每块最大混合 ⟹ 对角且块内两维等权）：
    中心态：diag(1/4,1/4,1/4,1/4)，**无离对角**
    rho_V ：diag(0,1/2,1/2,0) + 离对角 V/2（在 |01>,|10> 之间）
    ⟹ V≠0 时【有离对角项】⟹ **非中心**
    |rho_V[1,2]| = 0.5000（V=1 时）
  [PASS] rho_V 非中心（有离对角相干项） |rho_V[1,2]| = 0.5000

§4 判定：三条判定各自的作用域
================================================================================================

  ┌────────────────────────────┬──────────────────────┬──────────────────────────┐
  │ 判定                       │ 说的是哪个代数        │ 结论                     │
  ├────────────────────────────┼──────────────────────┼──────────────────────────┤
  │ Z036 定理 27 / §5.2        │ **同一个 𝒜_L 内**    │ 无双分划 ⟹ |S| ≤ 2      │
  │ Z008 定理 16               │ **复合 𝒜_L⊗𝒜_L**     │ S ∈ [2, 2√2] 两端可达    │
  │ Z008 定理 1(d)             │ 复合 + **中心态**     │ ρ⊗ρ 可分离 ⟹ 仍 |S| ≤ 2 │
  └────────────────────────────┴──────────────────────┴──────────────────────────┘

  ★ **不矛盾，因为作用域不同**：
     · 要把两个观测者放进**同一个** 𝒜_L  -> 不可能（定理 27）-> |S| ≤ 2
     · 要用**复合代数** 𝒜_L⊗𝒜_L          -> M₄ 块存在 -> 可到 2√2
     · 但复合里若态是**中心**的            -> 仍退化（定理 1d）

  ★★ **收口**：CHSH > 2 需要**两件事同时**：
     (i) 在**复合代数**里（不是单个 𝒜_L）；
     (ii) 态**非中心**（否则 ρ⊗ρ 可分离）。
     而"非中心"正是 Z027 命题 3 的门开条件
     ⟹ **CHSH 违反与非中心态同源**。

  [PASS] ★ 判定：Z036 与 Z008 不矛盾（作用域不同：单代数 vs 复合代数） 定理 27 管单代数；定理 16 管复合；定理 1d 管中心态
  [PASS] ★ 收口：CHSH>2 需要「复合代数 + 非中心态」两个条件 与 Z027 命题 3 同源：非中心 ⟺ 块内两支不等权
