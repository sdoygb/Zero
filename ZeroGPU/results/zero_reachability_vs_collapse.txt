§1 单方（B）穷举任意测量方向：分布会变吗？
================================================================================================
  B 穷举 20000 个测量方向（200×100）：
    max |p(A操作1) − p(A操作2)| = 1.11e-16
  ⟹ **B 无论怎么测（含理想无扰动测量），两个分布完全相同**
  [PASS] ★ 单方穷举任意测量方向，分布完全不变 ⟹ 不是测量扰动 max|Δp| = 1.11e-16

  【如果是「一查就变」造成的，会看到什么】
    · 测量【会】扰动，B 的分布应依赖测量方向/强度/顺序
    · 而这里：B 的分布对**任意**测量方向都一样 ⟹ **结构性，与测量无关**
    · 更关键：即使允许**理想（无扰动）测量**，也取不出（下面 §2 给出对照）

§2 若允许非局域联合测量（双方一起看）：能区分吗？
================================================================================================
  Bell 基（非局域）测量：
    A 操作 1 的分布 = [1.0, 0.0, 0.0, 0.0]
    A 操作 2 的分布 = [0.2057, 0.7943, 0.0, 0.7943]
    差              = [0.7943, 0.7943, 0.0, 0.7943]
  ⟹ **非局域联合测量【能】区分** ⟹ 关联**确实存在于那里**
     但这是【双方一起看】——**单方永远取不到**
  [PASS] ★ 非局域联合测量能区分 ⟹ 关联确实存在（不是不存在） max|Δp| = 0.7943

  ★★ 这一条正是「存在但不可查」的分界线：
     联合可访问（§2 能区分）＝ **存在**
     单方可提取（§1 恒 1 bit）＝ **不可查**

§3 判据：扰动型不可查 vs 结构型不可查
================================================================================================

  ┌────────────┬──────────────────────────┬──────────────────────────┐
  │            │ 扰动型（坍缩假说）        │ 结构型（Zero 的情形）     │
  ├────────────┼──────────────────────────┼──────────────────────────┤
  │ 原因       │ 测量扰动了态             │ 单方代数上取不到         │
  │ 若测量理想 │ **就能取出**             │ **仍然取不出**           │
  │ 依赖测量方向│ 是                       │ **否**（§1：恒不变）     │
  │ 依赖测量强度│ 是                       │ **否**                   │
  │ 联合测量   │ 能区分                   │ **能区分**（§2）         │
  │ 来源       │ 动力学（测量相互作用）    │ **代数**（Z008 定理 20） │
  └────────────┴──────────────────────────┴──────────────────────────┘

  Zero 属于**右列**：Z008 定理 20 的证明只用了"框架自带的运算都是保单位元的
  *-自同构" ⟹ **无条件成立**，**与测量扰动无关**。

  [PASS] ★ 判定：Zero 的不可查是结构型（代数无信号），不是扰动型 Z008 定理 20 无条件成立；§1 穷举测量方向恒不变

§4 Z008 §9 三条量的对照
================================================================================================
  V      I_q（关联总量）          I_acc（单方可取）        传信        
  0.0    1.000000           1.000000           0         
  0.5    1.188722           1.000000           0         
  1.0    2.000000           1.000000           0         

  ⟹ **I_q 涨到 2 bits（存在、联合可访问）；I_acc 恒 1 bit（单方可取）；传信恒 0。**
     **差的那 1 bit 就是"不可及"的部分** —— 它**存在**（§2 联合测量能区分），
     但**单方取不出来**（§1 恒不变）。**与"一查就变"无关。**

  [PASS] Z008 §9：I_q 可变（1→2 bits）、I_acc 恒 1 bit、传信恒 0 V=1→I_q=2 bits；V=0→I_q=1 bit
