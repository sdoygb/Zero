§4 验：为什么 CHSH 不可执行
================================================================================================
  𝒜_L = ⊕_{h=1}^{H} M_2(ℂ)，H = L/2 = 2，dim = 8，**每块 n_i = 2**

  ⟹ **S = 2√2 是代数层的数，不是任何人能测出来的数**

§6 两处校正
================================================================================================

  校正一：「根据我们得到的数据去算」——算不出来
    A 侧边缘态对 5 个 V 值：
      V=0.00 -> ρ_A = [[(0.5+0j), 0j], [0j, (0.5+0j)]]
      V=0.25 -> ρ_A = [[(0.5+0j), 0j], [0j, (0.5+0j)]]
      V=0.50 -> ρ_A = [[(0.5+0j), 0j], [0j, (0.5+0j)]]
      V=0.75 -> ρ_A = [[(0.5+0j), 0j], [0j, (0.5+0j)]]
      V=1.00 -> ρ_A = [[(0.5+0j), 0j], [0j, (0.5+0j)]]
    ⟹ 五个 V 给**完全相同**的 ρ_A ⟹ **V 从 A 侧数据不可辨识**
    ⟹ 「从数据算」算不出任何关于 V 的东西；
       真正的「算」是**条件计算**（给定假设的结构 ⟹ 推出 I_q），不是数据拟合
  [PASS] 校正一：V 从 A 侧数据不可辨识（数据对它完全失明） ρ_A 对 V=0..1 完全相同；max|Δ⟨M⟩|=0.00e+00

  校正二：「L2 层的一个部分」——也不准确
    L2 的代数 𝒜_L：dim = 4H = 8（H=2）
    复合代数 𝒜_L⊗𝒜_L：dim = 16H² = 64
    若「邻居」是 L2 的一部分 ⟹ 应在 𝒜_L 内（dim ≤ 8）
    但 Z036 定理 27：𝒜_L 内最多一个 M₂ ⟹ **𝒜_L 内没有第二个因子**
    ⟹ 「邻居」在 𝒜_L⊗𝒜_L 里、是**第二个因子**；
       而 𝒜_L⊗𝒜_L 是**由两份 𝒜_L 张起来的更大代数**，不是「L2 的一个子部分」
  [PASS] 校正二：「邻居」不在 𝒜_L 内（Z036 定理 27），而在 𝒜_L⊗𝒜_L 里 dim(𝒜_L)=8 < dim(𝒜_L⊗𝒜_L)=64

  ★ 用户自己做对的一步（重要）：
     主动把「空间」这个词撤回去了（「也不算空间吧」）。
     这一步避免了跨对象替换——「空间」是 L2 之上的恢复层输入（Z016 §3.4），

§8 「确定结果」四个字怎么理解
================================================================================================
  定义：**确定结果 = 这一回实际出现的那【一个】值**（不是分布，是那一个）

  具体例子 L=4：W_4 有 6 个平衡词
    (1, 1, -1, -1)   -> h = 2
    (1, -1, 1, -1)   -> h = 1
    (-1, 1, 1, -1)   -> h = 1
    (1, -1, -1, 1)   -> h = 1
    (-1, 1, -1, 1)   -> h = 1
    (-1, -1, 1, 1)   -> h = 2
    分布 b_h = {2: 2, 1: 4} ⟹ P(h=1)=4/6, P(h=2)=2/6

  结构给了：可能的词有哪些（6 个）、每个的概率（各 1/6）、按高度的分布
  结构没给：**这一次到底是哪一个词**（连 h=1 还是 2 都不给）
  ⟹ 这就是「确定结果」要补的那一格：实际走过的那一条路径
  [PASS] §8：结构给分布、不给'这一次是哪一个'（L=4 例） 6 个词；分布 4/6 vs 2/6；缺的是'哪一个'

  ★ 比'不知道结果'更狠：态连'该问哪个问题'都不指定（Z009 定理 9）
    ρ = diag(1/6, 1/6, 1/3, 1/3)；块 1 内取不同方向的 rank-1 投影：
      θ=  0.0° -> Tr(ρP) = 0.166667
      θ= 22.5° -> Tr(ρP) = 0.166667
      θ= 45.0° -> Tr(ρP) = 0.166667
      θ= 67.5° -> Tr(ρP) = 0.166667
    ⟹ 四个方向读数完全相同 = w₁/2 ⟹ **读数只依赖 rank，不依赖方向**
    ⟹ 这就是 Z007 定理 8「指针基是自由的」
  [PASS] §8：读数只依赖 rank（四个方向给同一值）⟹ 态不指定该问哪个问题 max|读数 − w₁/2| = 2.78e-17

  ★ 关键区分：「不确定」vs「态不指定」
     · 不确定（无知）：它确实是某一个，只是我不知道      （经典统计力学）
     · 态不指定（描述不完整）：描述里根本没有"是哪一个"  （Z009 推论 11.4）
     Z009 原文：不是"我们不知道"，而是**态不指定它**。

  ★ 逐环看来源：
     分布  <- 结构给（计数推前，Z004 定理 6）
     频率  <- 分布给（大数定律，Z004 定理 6.1）
     单次值 <- **没有来源**  ⟹ 只能额外输入（Z009 §8.4）

  [PASS] §8：结构→分布→频率三环都通，第四环'这一次是哪一个'没有来源 Z004 定理 6/6.1 通；Z009 §8.4 判额外输入
