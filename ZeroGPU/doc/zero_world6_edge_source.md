# 换对象：找 6 个边权重的来源

**性质**：讨论稿/拟合，不占正式篇号，不改变根目录 Z 篇的任何判定。
**脚本**：`ZeroGPU/src/zero_world6_edge_source.py`。
**数据**：`results/zero_world6_edge_source.json`、`zero_world6_edge_source.png`。
**复跑**：

```bash
cd ZeroGPU/src && /usr/bin/python3 zero_world6_edge_source.py
```

---

## 摘要

上一轮把"极端幂 p"消解为**跨度比**（不可辨识），来源应找在**边上**。本轮换对象：

- **固定源 + 映射**：4 个源取 Z126 振幅 / $u_s$ / seed，6 条边由 7 种映射给出；
- **自由源 + 映射**：4 个源也拟合。

$$
\boxed{\;
\text{6 条边的候选结构 = 4 个势的两两差；4 个势本身仍是输入（一个为 0）。}
\;}
$$

| 映射（自由源） | 夸克 RMS | 轻子 RMS | 幂 |
|:--|--:|--:|--:|
| **difference（势差）** | **0.898** | **0.840** | $-8.33$ |
| average（模型 A） | 1.297 | 1.973 | — |
| geometric | 0.845 | 1.101 | $-5.64$ |
| inverse | 0.989 | 0.763 | $7.80$ |
| ratio | 0.950 | 0.793 | $0.20$ |
| harmonic | 1.777 | 2.489 | — |

- **固定源全部失败**：最好的（seed + 比）也只到 1.053 dex（轻子差一点）；
- **自由源 + difference 双边通过**：0.898 / 0.840，$p=-8.33$，
  $w=(0.111,\;0.531,\;0,\;0.358)$——**一个势为 0**；
- **average 失败**：1.297 / 1.973（模型 A 的旧结果）。

---

## §1 读法

- **difference（势差）** 比 average（平均）更贴合：6 条边是 4 个势的两两差，
  这像一个**梯度/边场**结构（边承载端点势差）；
- 一个势为 0：4 个势可以固定一个规范（差不变），所以"一个 0"不奇怪；
- $p$ 仍是跨度比（上一轮已证不可辨识），不是新参数；
- **4 个势仍是拟合输入**，还没有来源。

---

## §2 判定

1. **边的候选结构找到了**：两两差（difference），不是平均；
2. **4 个势仍是输入**：$w=(0.111,0.531,0,0.358)$ 是拟合值；
3. **固定源（Z126 振幅/$u_s$/seed）都不行**：不能直接把这 4 个势等同于 Z126 的
   四个振幅或 $u_s$；
4. **下一步**：给这 4 个势找来源（或证明它们可由某个结构给出），再做 difference。

---

## §3 边界

1. 固定源测试只用了 7 种映射；别的映射（如 $w_i/w_j$ 的有理函数）未穷尽。
2. 幂仍极端（跨度比），但已不当作独立参数。
3. 质量目标含 3 个中微子（上限估计）。
4. 不是 Z 篇；无新量纲锚。
