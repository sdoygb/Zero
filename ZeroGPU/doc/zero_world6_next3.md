## §1 4 势来源：K4 谱与 Z126 零点都不行

4 势（差不变，去均值后）$w_c=(-0.139,0.281,-0.250,0.108)$。

**K4 谱组合**：K4 的 $-1$ 空间是 3 维，任何"去均值的 4 向量"都在其中（$w_c$ 的
范数 $0.415$ 全在 $-1$ 空间）——**K4 谱不选出方向**，组合是平凡的。

**Z126 零点/振幅变换**（有序 $\cos$，无置换）：

| 候选 | 有序 $\cos$ |
|:--|--:|
| $1/A$ | 0.223 |
| $\theta^*=\pi-\arccos(1/A)$ | 0.288 |
| $\theta^*-\pi/2$ | 0.288 |
| $\log A$ | $-0.116$ |
| $A^2$ | 0.070 |
| $\cos\theta^*$ | $-0.223$ |
| seed | $-0.111$ |
| $1/\text{seed}$ | $-0.020$ |

全部 $|\cos|<0.3$——**没有对齐**。4 势仍无来源。

## §2 λ=10 的 10^5 代：未收敛

| 量 | 值 |
|:--|:--|
| 份额 | $0.313,\;0.451,\;0.236$ |
| relstd | $0.196,\;0.139,\;0.071$ |
| 漂移（每 200 代） | $-1.5\times10^{-6}$ |
| 尾段前半 | $0.390,\;0.353,\;0.257$ |
| 尾段后半 | $0.278,\;0.494,\;0.228$ |
| $n_{std}$ | $1.195$ |
| 有界/无 NaN | 是 |

- 5000 代时 λ=10 的 relstd 还在 0.06–0.10；到 $10^5$ 代，relstd 反而升到
  $0.20/0.14/0.07$，尾段前后份额明显移动（$0.39\to0.28$）；
- **没有收敛到固定点**，是慢漂/慢振荡；$\lambda=10$ 的"稳定"是**暂态**。

## §3 λ 进质量模型：无影响

把 18 引擎（γ=2, λ=10）的份额 $S=(0.353,0.437,0.210)$ 作为质量模型的代权重，
$b=\sum_g S_g e^{p_g}$：

| 模型 | 夸克 RMS | 轻子 RMS |
|:--|--:|--:|
| 单幂（$p$ 共用） | 0.989 | 0.763 |
| 三幂（自由） | 0.840 | 0.780 |
| 对照（之前 free，无 S） | 0.824 | 0.787 |

- 单幂与"等权"版本**逐位相同**；
- 三幂只差 0.02 dex；
- **质量拟合对代权重不敏感**（代权重被幂/标度吸收）；λ 没有传进质量模型。

---

## §4 判定

1. **4 势仍无来源**：K4 谱平凡、Z126 零点/振幅变换不对齐。
2. **λ=10 长程未收敛**：$10^5$ 代仍慢漂/慢振荡；5000 代的"稳定"是暂态。
3. **λ 进质量模型无影响**：质量拟合对代权重不敏感，λ 不传播。
4. **瓶颈仍是 4 势**；γ/λ 是另一条动力学线，既不收敛也不影响质量。

## §5 下一步（需要换思路）

1. **重新审视"4"这个顶层**：4 势若不是一个 4 向量（seed/振幅/零点都不是），
   也许顶层不是 4 个标量，而是别的对象（4 维表示、4 个零点、4 个质量层标度）；
2. **或接受 4 势为具名输入**，把质量映射登记为"4 输入 + 2 锚"的拟合（不冒充预言）；
3. **γ/λ 线先停**：不收敛、不影响质量，除非找到稳定化机制或它们的观测对应；
4. **长跑基线回到 γ=0**（稳定，2×10^4–10^5 代可跑）。
