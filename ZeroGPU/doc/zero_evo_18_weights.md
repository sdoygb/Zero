# 18 世界自己的动力学能产出代权重吗？

**性质**：讨论稿/否定结果，不占正式篇号，不改变根目录 Z 篇的任何判定。
**脚本**：`ZeroGPU/src/zero_evo_18_weights.py`。
**数据**：`results/zero_evo_18_weights.json`、`zero_evo_18_weights.png`。
**复跑**：

```bash
cd ZeroGPU/src && /usr/bin/python3 zero_evo_18_weights.py
```

---

## 摘要

去掉 `gen_w` 输入（初始 3 代均匀），让 18 世界**自己跑**，试四种毁灭规则 + 两种
反馈，看它能否产出观测的轻子层级：

$$
\boxed{\;
\text{不能。18 世界的层动力学只给：均匀、死一代、或赢者通吃；}
\text{观测层级需要质量算符（Z126）。}
\;}
$$

| 变体 | 产出的 3 代份额 | 对观测的 max err |
|:--|:--|--:|
| match（每代留匹配） | $0.333,0.333,0.333$ | 0.46 |
| top1（每代留最大边） | $0.333,0.333,0.333$ | 0.46 |
| top2（整体留 2 通道） | $0.500,0,0.500$（**一代死**） | 0.49 |
| all（不毁灭） | $0.333,0.333,0.333$ | 0.46 |
| match + 反馈 $\eta=0.5$ | $0.770,0.116,0.114$ | 0.76 |
| match + 反馈 $\eta=2$ | $1,0,0$（**赢者通吃**） | 0.99 |
| **观测 $\sqrt m$ 归一** | $0.0135,0.1934,0.7931$ | — |

**没有一条接近观测**：要么三代一模一样，要么死一代，要么赢者通吃；方向和形状
都不对（观测是重代 $\tau$ 主导，反馈给的是 gen0 主导）。

---

## §1 为什么

- **无反馈**：3 个完美匹配的总源相同（每个都覆盖 4 个顶点），所以份额被拉平到
  $1/3$；top1 也在归一化后回到 $1/3$。
- **top2**：整体只留 2 个通道，通常落在同一个/两个匹配里，于是至少一代死掉。
- **反馈**：源被影子调制，正反馈放大"源最大的那一代"，最终赢者通吃（$\eta$ 越大
  越快）。这是**选择**，不是**层级**；它给不出 1:14:59 这种中间态。

**根本原因**：18 世界的层动力学是对称的（3 个匹配等价），要产生层级必须有
**对称破缺的参数**；一旦加参数（$\eta$、top-k），结果要么是均匀、要么是极端
（0/1），中间的大层级不是它的固定点。

---

## §2 判定

**18 世界自己的动力学产不出观测的代权重。** 这不否定 18 世界——它说明分工：

- **18 世界**：层/代结构（3 代 × 6 边、影子 6、T=4、匹配毁灭）；
- **质量算符（Z126）**：质量数值 $m=u A^2[1+A\cos\theta]^2$。层级来自 $\cos\theta$
  接近零点（$1+A\cos\theta\to0$），不是来自层动力学的对称破缺。

所以上一步的"校准到轻子层级"只能是**校准**；要变成**预言**，必须把相位 $\theta$
接进 18 世界（每代一个 $\theta_g$），让质量算符产出代权重。

---

## §3 下一步（预言路线）

1. 从 Zero 的相位结构（Z121/Z123：零点、间隔、$\delta_0$）取三个 $\theta_g$；
2. 用 Z126 的 $m_g=uA^2[1+A\cos\theta_g]^2$ 算三个质量；
3. 把 $\sqrt{m_g}$ 归一作为 18 世界的代权重，跑引擎；
4. 比较产出的份额与观测——这一步才是"动力学/算符产出权重"，不是拟合观测。

若第 1 步的 $\theta_g$ 是 Zero 内生（Z121/Z123 已给出），第 4 步就是预言；若还要
调 $\theta_g$ 去对质量，就仍是校准。
