# 16/8/4 纤维塔：top-down 核必须 base-dependent

## 结论

**16/8/4 能承载 3 个 L2 槽；但“从顶映射下来”不能是一个全局纤维分布。**

- 全局纤维分布 $q$（所有 base 相同）→ 3 个非平凡字符**秩 1**；
- **base-dependent** 纤维核 $Q$（每个 base 的纤维分布不同）→ **秩 3**。

$$
\boxed{\;
\text{16/8/4 是必要骨架；完整映射还需要 base-dependent 的 top-down 连接。}
\;}
$$

![纤维塔](ZeroGPU/results/zero_fiber_topdown.png)

## 结构

$$
16=4\times(\mathbb Z_2\times\mathbb Z_2)
\;\longrightarrow\;
8=4\times\mathbb Z_2
\;\longrightarrow\;
4=4.
$$

- 顶 4 = base（K4 顶点）；
- 纤维 $\mathbb Z_2\times\mathbb Z_2$ 有 **4 个字符**：1 个平凡 + **3 个非平凡**；
- 这 3 个非平凡字符就是 L2 的 3 个槽的候选。

## 静态秩测试

取 base 权重

$$
t=(1,0.8,0.6,0.4),
$$

纤维分布

$$
q=(0.4,0.3,0.2,0.1).
$$

### 1. 全局 $q$：所有 base 用同一个纤维分布

$$
X_g=t\,q^{T}.
$$

3 个非平凡字符的奇异值：

$$
[0.3286,\;0,\;0]
\quad\Longrightarrow\quad
\boxed{\text{秩}=1.}
$$

**原因**：每个 base 的纤维形状完全相同，3 个字符只差一个全局系数，张成 1 维。

### 2. base-dependent $Q$：每个 base 的纤维分布不同

$$
Q=
\begin{pmatrix}
0.4&0.3&0.2&0.1\\
0.1&0.4&0.3&0.2\\
0.2&0.1&0.4&0.3\\
0.3&0.2&0.1&0.4
\end{pmatrix},
\qquad
X_d=\operatorname{diag}(t)\,Q.
$$

3 个非平凡字符的奇异值：

$$
[0.2433,\;0.1896,\;0.1133]
\quad\Longrightarrow\quad
\boxed{\text{秩}=3.}
$$

**两组的每行都是全支撑**；区别只在**是否 base-dependent**。

## 这说明什么

- **全支撑不够**：全局 $q$ 也覆盖 4 个纤维点，但 3 个字符仍秩 1；
- **完整映射要求**：每个 base 的纤维连接不同，即 $Q_{v f}$ 依赖 base $v$；
- **单值映射更不够**：单值映射只是 $q$ 为一个 delta，连全支撑都没有；
- **6/18/4**：没有 $\mathbb Z_2\times\mathbb Z_2$ 纤维，连 3 个字符都定义不出来——所以它不能承载 L2 的 3 槽。

## 与当前 16/8/4 引擎的关系

当前引擎的 3 个非平凡纤维模：

$$
[1.80\times10^{-7},\;1.78\times10^{-8},\;1.78\times10^{-8}],
\qquad
\text{秩}=1.
$$

这正好对应“**全局 q**”的情形：纤维形状不随 base 变，所以 3 个字符退化成一个。

**L2 不完整的原因不是 16/8/4 选错，而是 top-down 核是 base-independent 的。**

## 判据（3/3）

1. 全局 $q$ 的 3 字符秩=1：PASS（$0.329,0,0$）；
2. base-dependent $Q$ 的 3 字符秩=3：PASS（$0.243,0.190,0.113$）；
3. $Q$ 每行全支撑：PASS。

**这是静态结构测试，不是动力学推导。**

## 边界

- $Q$ 是**选的**，不是从 L0/L1 推出的；
- 静态测试只证明“base-dependent 能到秩 3”，不证明“Zero 的 Q 就是它”；
- 真实动力学还要让 $Q$ 随 L1/L0 演化，而不是固定矩阵；
- 3 个字符是否是物理 L2 槽，仍需定义。

## 下一步

1. **从 L0/L1 推 $Q$**：为什么每个 base 的纤维连接不同？不能拍一个 $4\times4$ 矩阵；
2. **让 $Q$ 动态**：$Q$ 应随 L1 高度/面积或 L0 闭合变化；
3. **检验 3 个字符的物理意义**：它们是否对应 3 个频率槽，而不是数学上的字符。

**一句话**：16/8/4 是唯一能承载 3 个非平凡纤维字符的骨架；但**全局 top-down 分布只给秩 1**，必须 **base-dependent** 才能到秩 3。当前引擎正是全局型，所以 L2 退化成 1 个模式——缺的不是 16/8/4，是 **base-dependent 的纤维连接**。
