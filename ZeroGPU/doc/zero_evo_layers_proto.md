# L0–L1–L2 层集成 prototype：只完成了“部分”

## 结论

**仍然不是完整的 L0–L1–L2 动力学。**

这次接了三样：

- **L0**：`l0_back` 反馈（L2 记录回写 seed）；
- **L1**：静态高度/面积读出 $b_h=[4,2]$、$A_h=[3,2]$；
- **L2**：从 16 类记录取 4-site 占据，算 **3 个相邻比（频率槽）**。

但：

- **L1 只有静态读出，没有高度层动力学**；
- **L2 的 3 个槽在“相邻比”坐标下只有 1 个非零**（另外两个是 $10^{-4}$ 残余）——但这是坐标依赖的，不变对象是 4-site 占据；
- **L0 反馈能改内容，但 $l0\_back=0.3$ 时 $n_{std}=1.148>1$**，已经接近/超过有界线。

## 分槽根据：相邻比是一个坐标，不是三个不变槽

`zero_layers.l2_metrics` 的定义是：

$$
p=(p_0,p_1,p_2,p_3),\qquad
\sum p_i=1,\qquad
f_i=\left|\log\frac{p_i}{p_{i+1}}\right|,\quad i=0,1,2.
$$

4 个 site 只有 3 个独立自由度，所以“3 个槽”= **3 个相邻比**，这是一个**坐标选择**，不是三个不变物理模式。

### 同一个 $p$，换基就变

对 $p=[0.6711,0.10964,0.10963,0.10962]$：

**相邻比坐标**：

$$
f=[1.8117,\;1.16\times10^{-4},\;1.13\times10^{-4}]
\quad\Longrightarrow\quad
\text{看起来只有 1 个槽。}
$$

**正交单纯形基**（Helmert）：

$$
e_1=\frac{(1,-1,0,0)}{\sqrt2},\;
e_2=\frac{(1,1,-2,0)}{\sqrt6},\;
e_3=\frac{(1,1,1,-3)}{\sqrt{12}}.
$$

同一个 $p$ 的系数：

$$
(c_1,c_2,c_3)=(0.397,\;0.229,\;0.162),
$$

**三个都非零。**

### 所以

- “1 大 + 2 个 $10^{-4}$ 残余”是**相邻比坐标**下的读数；
- **不变对象**是 4-site 占据 $p$；
- $p$ 的形状是“1 个高 + 3 个相等”，这是一个**一维对称子流形**；
- 换成正交基，3 个分量都非零，但协方差秩仍是 1——**非零分量 ≠ 3 个独立槽**。

**结论**：不能把“相邻比只有 1 个非零”说成“L2 只有 1 个槽”；这是**坐标依赖**的。

## 判据（5/5，但只是结构判据）

1. L1 静态 $b_h/A_h$ 可读出：PASS；
2. L2 有 3 个槽：PASS（相邻比坐标下两个为 0；正交基下三个非零）；
3. 无 NaN：PASS；
4. $l0\_back$ 改变动力学：PASS；
5. L2 槽有周期 4：PASS（相邻比坐标下只有第一个槽非零）。

**这 5 条不能证明“L0–L1–L2 完整动力学”；只证明接线能跑。**

## 还缺什么

| 项 | 状态 |

| L2→L0 $q_{live}$ 闭环 | ✅ 通过 `l0_back` 部分接上 |
| L0→L2 结构回写 | ❌ 只有 seed 调制 |

## 边界

- **L1 明确没有自身更新律**（`zero_layers.py` 已说），所以“L1 动力学”本身在现有公理里是**静态读出 + 记录累积**，不是独立演化；
- **L2 3 槽**需要 4 个 site 都有非零占据；当前记录只有 2 个 site，所以只有 1 个槽；
- $l0\_back=0.3$ 的 $n_{std}>1$ 说明反馈可能过强；需要定有界条件；
- 16/8/4 仍是 L2 亚层代理，不是 3 槽。

## 下一步

1. **让 4 个 site 都非零**：加 seed/flow 或对称化，使 L2 的 3 个槽都非平凡；否则“3 槽”只是名义上的。
2. **L1 高度/面积记录**：把闭合按高度/面积累积，而不只是静态 $b_h/A_h$；但注意 L1 无自身更新律。
3. **定 $l0\_back$ 有界条件**：$0.1$ 时 $n_{std}=0.972$，$0.3$ 时 $1.148$；需要找稳定上界，而不是继续加大。

**一句话**：这次只接上了 **L0 反馈 + L1 静态读出 + L2 名义 3 槽**；L2 实际只有 1 个非零槽，L1 没有动力学——**仍不是完整的 L0–L1–L2 动力学**。
