# 引擎里的 base-dependent Q：静态能到秩 3，动态注入不存活

## 结论

**把 base-dependent $Q$ 以“每代混合/注入”的方式塞进 16/8/4 引擎，纤维模仍然起不来。**

- 静态矩阵测试：base-dependent $Q$ 的 3 个非平凡字符奇异值 $[0.243,0.190,0.113]$，秩 3；
- 放进引擎后：3 个纤维模的协方差**秩 0**（模本身在 $10^{-7}$ 以下）；
- 原因不是 $Q$ 选错，而是：**$A_4^L$ 的传播 + 归一化/flow 把纤维差异抹平了**。

**所以 base-dependent $Q$ 是必要条件，但不是充分条件；必须在“源”上打破纤维对称，而不是在传播后补。**

## 引擎里看到什么

把 $Q$ 以

$$
W_b \leftarrow 0.9\,W_b+0.1\,Q
$$

注入后，第 1–3 代的 $W_b$ 是**近循环矩阵**：

$$
W_b\approx
\begin{pmatrix}
0.0598&0.0567&0.0563&0.0559\\
0.0559&0.0598&0.0567&0.0563\\
0.0563&0.0559&0.0598&0.0567\\
0.0567&0.0563&0.0559&0.0598
\end{pmatrix}.
$$

- 每行只差 $10^{-3}$；
- 3 个非平凡纤维字符的功率在 $10^{-7}$ 以下；
- 协方差秩 $0$。

**$Q$ 的 base-dependence 被 $A_4^L$ 的循环化和归一化吃掉了。**

## 为什么

1. **$A_4^L$ 是 base 上的传播**，但它对纤维列做的是**相同的线性组合**；
2. $Q$ 注入后，$W_b A_4^L$ 把 base 差异抹成近循环；
3. 归一化/flow 进一步把所有行拉向同一尺度；
4. 结果：纤维方向只剩 $10^{-7}$ 的残余。

**“静态 $Q$ 秩 3”只说明矩阵本身能承载 3 个字符；不说明它在动力学里能存活。**

## 判定

| 说法 | 判定 |
|:--|:--|
| base-dependent $Q$ 静态能到秩 3 | ✅ |
| 把 $Q$ 注入引擎就能到秩 3 | ❌（秩 0） |
| 16/8/4 能承载 3 槽 | ✅（结构上） |
| 当前引擎的 L2 完整 | ❌ |

## 缺的是什么

不是 $Q$ 的数值，而是：

1. **纤维不对称的源**：seed/L1 记录必须在纤维上不同，而不是 base 上不同；
2. **不与 $A_4^L$ 对易的纤维操作**：如果纤维混合和 base 传播对易，它会被传播平均掉；
3. **初始纤维态**：不能从“纤维全等”的初值出发，否则任何混合都不产生差异。

## 后续：seed 注入和非循环 $Q$ 也不行

在“每代混合”失败后，又试了两条：

1. **seed 注入**：把 $Q$ 作为底 16 的初始/每代 seed（$W_b\leftarrow W_b+\frac13Q$）；
2. **非循环 $Q$ 混合**：$Q$ 不再取循环矩阵，改成行互不相同的非循环矩阵，再 $W_b\leftarrow0.5W_b+0.5Q$。

结果：

| 方案 | 3 个纤维模 | 秩 |
|:--|:--|--:|
| seed 注入 | $\sim10^{-7}$ | 0–1 |
| 非循环 $Q$ 混合 | $\sim10^{-6}$ | 1 |
| 非循环 $Q$ 混合，第 2000 代 | $W_b$ 四行全相等 | 0 |

**$A_4^L$ 的 base 传播 + 归一化/flow 仍然把纤维差异抹平。**

## 判定更新

- 不是“$Q$ 选得不够好”；换 seed、换非循环 $Q$ 都救不回来；
- **16/8/4 的类状态 $W_b$（4×4）本身没有承载纤维秩 3**：它被 base 传播和归一化压成近循环/全等；
- 要继续，必须**改状态变量**或**改耦合顺序**，不是继续调 $Q$。

## 下一步

1. **在 seed 上打破纤维对称**：给每个 base 的 4 个纤维类不同的初始权重（不是每代补）；
2. **让纤维操作在 $A_4^L$ 之前**，或构造非对易的纤维-base 耦合；
3. **再测秩**：如果仍然秩 0，说明 16/8/4 的类动力学本身没有承载纤维模，需要改状态变量，而不是改 $Q$。

**一句话**：静态 $Q$ 能到秩 3，但**注入引擎后不存活**——$A_4^L$ 和归一化把纤维差异抹平了。下一步必须在 **seed/初始纤维态**上打破对称，而不是在传播后补 $Q$。
