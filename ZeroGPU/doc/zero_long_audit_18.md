## 摘要

2026-10-18 的 `zero_long_audit.md` 用 **16/8/4** micro core 判了「形状冻结」。
此后用户改判当前亚层模型为 **18 世界**（$4\to18\to6$，3 代 × 6 边；
`zero_l2_partitions.md` §8.2、`zero_evo_18.md`），但 18 core 的长跑只做到
$10^4$ 代、且当时没有冻结判据。本稿把同一套判据搬到 18 core，并追问
「冻结的是哪一层」。

$$
\boxed{\;
\begin{aligned}
&\text{① 冻结的是**宏观形状**，不是进程；18 core 在 }1.95\times10^4\text{ 代冻结，}\\
&\quad\text{到 }3\times10^6\text{ 代无逃逸。}\\
&\text{② 在 long-audit 的 full 参数下，18 core 与 16/8/4 core 的宏观量}\\
&\quad\text{**逐位相同**（$\max$ 差 $=0$）——因为 }\alpha=0\text{ 使 L2 完全没有回写宏观。}\\
&\text{③ 把 }\alpha\text{ 打开后两者立刻分道（差 }67\text{–}72\text{）；}\\
&\quad\text{耦合版长跑**不冻结**：平稳涨落、变幅大 }10^5\text{–}10^6\text{ 倍。}\\
&\text{④ 层份额在 }\gamma=0\text{ 时恒等于输入 }\texttt{gen\_w}\text{——是构造，不是动力学。}\\
&\text{⑤ C3 手征步能解除 K4 的秩 1 退化，且让层份额第一次“活”起来。}
\end{aligned}
\;}
$$

**读法**：

1. **18 core 的宏观形状在第 $1.95\times10^4$ 代冻结**（判据：连续 5 个 500 代
   block 的相对变化 $<10^{-10}$），到 $3\times10^6$ 代没有迟到逃逸。全程
   $n_{std}$ 只动了 $4.9\times10^{-7}$、$q$ 只动了 $1.3\times10^{-7}$——
   已经落在浮点噪声里。
   **注意**：用**同一判据**测 16/8/4 core，冻结起点也是 $1.95\times10^4$ 代
   （逐位相同，见 §2）；10-18 审计报的「$\sim2\times10^4$ 步」与之一致。
   **本稿不主张"18 比 16/8/4 冻得更早"**——在 $\alpha=0$ 下两者是同一个动力学。
2. **full 的判据报 `ok` 而不是 `frozen`，是因为 $\psi_{\rm coh}$**：`record_sum`
   虽在长（每代 $+1$），但本脚本的判据**不含 `record_sum`**（只用形状量）；
   真正让"所有量都不动"不成立的是**波相位相干** $\psi_{\rm coh}$——它每 block
   相对变化 $8\times10^{-4}$–$2\times10^{-2}$，是唯一还在动的量。
   这与 10-18 审计 §读法第 2 条**逐字一致**：**全引擎的波相位是唯一的持续运动，
   它是定态上的相位旋转，不产生新结构。** 物质/几何的形状已冻结。
3. **micro-only 报 `frozen`**：几何/波扇区关闭 $\Rightarrow\psi_{\rm coh}$ 恒为
   $0$，形状量逐位不变（全程 $|\Delta|=0$），故连续 5 个 block 的相对变化
   全 $<10^{-12}$。**两个运行的差别不是"一个冻了一个没冻"，而是
   "波扇区开着所以还有一个相位在转"。**

## §2 18 core 与 16/8/4 core 在 full 参数下逐位相同

把两个 core 放在**同一套** 12 通道参数下逐代比较 $2\times10^4$ 代：

| 量 | $\max|18 - 16/8/4|$ |
|:--|--:|
| `n_std` | $\mathbf{0.000\times10^{0}}$ |
| `q` | $\mathbf{0.000\times10^{0}}$ |
| `h_energy` | $\mathbf{0.000\times10^{0}}$ |
| `psi_coh` | $\mathbf{0.000\times10^{0}}$ |
| 内容向量 `n`（逐分量） | $\mathbf{0.000\times10^{0}}$ |

**逐位相同**，不是"接近"。但两个 core 的**内部状态完全不同**：

| 内部量 | 18 core | 16/8/4 core |
|:--|--:|--:|
| `seed` | $[0.25,0.25,0.25,0.25,0,\dots]$ | $[0.698,0.031,0.031,0.031,0.024,0.024]$ |
| `record`（第 200 代） | $200.0$ | $2099.08$ |
| $\max|\text{seed 差}|$ | — | $0.448$ |
| $\max|\text{record 差}|$ | — | $921.9$ |

**根因（读代码得）**：`ZeroEvo.step()` 里 micro 回写宏观只有两条通道——
`_closure_update()`（边③，`alpha`）与 `_seed_used()` 的 $\eta_*$ 调制。
而 10-18 审计的 full 参数是 `alpha=0`、`eta_*=0`，于是
`_closure_update()` **在 `alpha <= 0` 时直接 return**，`_seed_used()` 也不受
宏观调制。**micro core 退化成纯旁观者**，宏观自己跑自己的固定点。

$$
\text{micro 影响宏观的通道}
= \underbrace{\alpha}_{\text{边③ 闭合}\to\text{内容}}
+\underbrace{\eta_n,\eta_h,\eta_\psi}_{\text{内容/几何/波}\to\text{seed}} .
$$

两者都为 $0$ 时，**选哪个 micro core 在宏观上不可观测**。这解释了
`zero_evo_cores.md`（5000 代）的同一结论，并把它从 5000 代推到 $2\times10^4$ 代。

**这是一条对 10-18 审计的更正**：`zero_long_audit.md` 把该配置称作
"12 通道全开"，但按上述口径它**并未把 L2 接回宏观**；其「形状冻结」结论
因此是关于**宏观自身固定点**的，不是关于 L2 动力学的。

## §3 打开耦合后：两个 core 立刻分道，且不冻结

把 $\alpha$ 与 $\eta_*$ 打开，扫四组配置，各跑 8000 代：

| 耦合 | $\max|18 - 16/8/4|$ | 18 core 尾段 $n_{std}$／$q$ |
|:--|--:|:--|
| 全关（10-18 审计原参数） | $0.000\times10^{0}$ | $1.644484$／$0.116630$ |
| `alpha=0.1` | $6.74\times10^{1}$ | $1.753833$／$0.247999$ |
| `alpha=0.3` | $7.16\times10^{1}$ | $1.751725$／$0.249479$ |
| `eta=0.2`（只开 $\eta_*$） | $0.000\times10^{0}$ | $1.644484$／$0.116630$ |
| `alpha=0.3 + eta=0.2` | $7.15\times10^{1}$ | $1.743567$／$0.250613$ |

- **`alpha` 是唯一的分道闸门**：开了就分道（差 $\sim70$），不开就逐位相同。
- **只开 $\eta_*$ 仍然逐位相同**：$\eta_*$ 只是调制**源 4 的幅度**，
  而源在 18 core 里只进 `flow`，`alpha=0` 时 `flow` 根本不进 `W18`。
- 分道后 $q$ 从 $0.1166$ 跳到 $\sim0.25$，**翻倍**——这是 18 core 与 16/8/4
  core 在宏观上真正不同的第一个证据。

**耦合版长跑**（`alpha=0.3, eta=0.2`，$2\times10^6$ 代，492.3 s，4062 步/s）：
状态 `ok`，**不进入任何平台**，且判据报出**周期 $2\times10^4$ 代**。

| 量 | 全程统计（$2\times10^6$ 代） |
|:--|:--|
| $n_{std}$ | 均值 $1.752198$，范围 $[1.701594,\;1.836876]$，变幅 $1.35\times10^{-1}$（rel $7.7\times10^{-2}$） |
| $q$ | 均值 $0.253493$，范围 $[0.249285,\;0.279771]$，变幅 $3.0\times10^{-2}$（rel $1.2\times10^{-1}$） |
| $h_E$ | 均值 $36.225$，范围 $[33.668,\;39.392]$ |
| 前半段 $n_{std}$ | 均值 $1.75246966$，std $1.94\times10^{-2}$ |
| 后半段 $n_{std}$ | 均值 $1.75192633$，std $1.90\times10^{-2}$ |

**前后半段均值只差 $5.4\times10^{-4}$、而 std 恒为 $\sim1.9\times10^{-2}$**：
这是一个**平稳的非平凡吸引子**——持续涨落、不漂移、不收敛到固定点、
也不爆掉。它既不是 10-18 审计里的固定点，也不是发散。

| 量 | 全关（$3\times10^6$ 代） | 耦合（$2\times10^6$ 代） | 比 |
|:--|--:|--:|--:|
| $n_{std}$ 全程变幅（相对） | $4.9\times10^{-7}$ | $7.7\times10^{-2}$ | $\sim10^{5}$ |
| $q$ 全程变幅（相对） | $1.3\times10^{-7}$ | $1.2\times10^{-1}$ | $\sim10^{6}$ |

**即：$\alpha$ 打开后，宏观进入持续振荡而不是固定点；冻结消失，
差距是 5–6 个数量级。** 这是「18 世界作为 micro core」产生真实动力学的
第一个必要条件（注意：$\alpha>0$ 本身是 Z129 边③，不是新输入）。

## §4 层份额：$\gamma=0$ 时是构造，不是动力学

18 core 的层份额 $\text{share}_g=W_{18}[g]\cdot/\sum W_{18}$ 在**第 0 代就等于
输入权重 `gen_w`**，且 $5\times10^4$ 代不变：

| 量 | 值 |
|:--|:--|
| `gen_w`（3 槽 $\log2,\log(8/3),\log1.5$ 归一） | $(0.333333,0.471679,0.194988)$ |
| 第 0 代份额 | $(0.333333,0.471679,0.194988)$ |
| 第 $5\times10^4$ 代份额 | $(0.333333,0.471679,0.194988)$ |
| 每代质量 $/\texttt{gen\_w}$ | $(1,1,1)$ |

**这正是 `zero_evo_18.md` 限制 #1 的实测确认**：份额由代权重与"每代留自己的
匹配"规则固定，宏观只改源的幅度。所以 §1 里「层份额冻结」是**平凡冻结**
（输入常数），不是动力学结论。

代依赖耦合 $\gamma_{\rm gen}$ 是唯一的例外（`zero_evo_cores.md`）：

| $\gamma_{\rm gen}$ | 尾段份额 | 尾段 relstd |
|--:|:--|:--|
| $0$ | $(0.3333,0.4717,0.1950)$ | $(0,0,0)$ |
| $2$ | $(0.4694,0.2554,0.2752)$ | $(0.190,0.332,0.161)$ |

$\gamma>0$ 让份额动起来，但**不收敛**（relstd $0.16$–$0.33$），与
`zero_evo_18_stab.md`「长程不稳」一致。

## §5 对照最新分层理论：K4 的秩 1 退化与 C3 手征

`zero_l2_three.md` 命题 2 判定：K4 顶点传递 $\Rightarrow A^L=\alpha I+\beta J$
$\Rightarrow$ 在 $1^\perp$ 上 $J_c=\frac{1}{81}I$，**三个亚层方向本征值全同
（秩 1）**；并给出补全方案 C3 手征步 $(AP)^L$，给 $\frac{1}{81}(1,\omega,\omega^2)$。
本稿**独立复算并首次接进引擎**（`zero_chiral_18.py`，8/8 判据）：

| # | 判据 | 结果 |
|--:|:--|:--|
| 1 | 静态：plain $A^4$ 在 $1^\perp$ 上 1 个不同本征值 | PASS，$\lambda=0.012346\times3=1/81$ |
| 2 | 静态：手征 $(AP)^4$ 给 3 个不同本征值 | PASS，$\{0.012346,\;-0.006173\pm0.010692i\}$ |
| 3 | 静态：plain 形状轨迹秩 $=1$（理论对象） | PASS |
| 4 | 静态：手征形状轨迹秩 $=3$ | PASS |
| 5 | 引擎：两个 core 的逐代闭合轨迹秩 | PASS，均 $=3$ |
| 6 | 手征 core 有界／非负／无 NaN | PASS |
| 7 | 手征改变层份额 | PASS，plain $(0.333,0.472,0.195)$ vs 手征 $(0.359,0.292,0.349)$ |
| 8 | 手征的层份额不冻结（plain 恒为 `gen_w`） | PASS，tail relstd 手征 $(0.021,0.021,0.015)$ vs plain $(0,0,0)$ |

**三点值得记**：

1. **理论复算通过**：$1/81=0.012345679$ 与 `zero_l2_three.py` 的
   `shape_jacobian` 逐位一致（第一遍我用**未归一化**的 $A^L$ 直接取本征值，
   得到 $1$ 而不是 $1/81$，是漏了分母 $d^L$——口径坑）。
2. **引擎里看不到这个退化**：plain core 的逐代闭合轨迹秩也是 $3$。
   原因是**引擎不在 Perron 点**：`persistent` 口径下种子是不对称的
   $[8,4,1.5,1]$，闭合序列被 seed 驱动，不是纯 $J_c^t x_0$。
   **理论的秩 1 是"形状映射在对称固定点附近"的性质，引擎的秩 3 是
   "不对称输入驱动"的性质——两者不矛盾，但判据必须用对对象。**
   （第一版脚本拿**累积 `record`** 算秩，得 3；那是单调增长的和，口径错。）
3. **C3 手征是第一个让层份额真正动起来的机制**：份额
   $(0.333,0.472,0.195)\to(0.359,0.292,0.349)$ 且尾段 relstd $\sim0.02\neq0$。
   代价：C3 作用在**代指标**上必须是 **3-循环** $(0\to1\to2\to0)$，
   **不能**把 4 顶点的 $C_3$ 置换切成 $3\times3$——那会得到奇异矩阵
   （实测：行 2 全零，`W18` 第三代被清零）。3 代是 K4 的 3 个 1-因子，
   它们之间的循环是 3 阶的（对应 Z090 的 $1\oplus\omega\oplus\omega^2$）。

## §6 判定与边界

1. **冻结的是宏观形状，不是进程**；18 core 在 $1.95\times10^4$ 代冻结，
   到 $3\times10^6$ 代无逃逸。**在 $\alpha=0$ 下这与 16/8/4 core 是同一个
   动力学**（逐位相同），故本稿不主张两者冻结时刻有差别。
2. **10-18 审计的 full 配置实际未接 L2 回宏观**（$\alpha=\eta_*=0$），
   故其「18 与 16/8/4 无差别」不是物理等价，而是**耦合缺失**。
3. **打开 $\alpha$ 后分道，且长跑进入平稳涨落而非固定点**（$2\times10^6$ 代，
   变幅大 $10^5$–$10^6$ 倍，前后半段统计相同）——这是 18 世界
   作为 micro core 产生可观测差异的**必要条件**。
4. **层份额在 $\gamma=0$ 时是输入常数**；$\gamma>0$ 能动但不收敛。
5. **C3 手征能解除 K4 退化并激活层份额**，但它**不在任何演化引擎里**
   （只在 `zero_l2_three.py` / `zero_l2_partitions.py` 的分析脚本里），
   且"每代转一次"是**建模选择**，不是从 L0/L1 导出的（`zero_l2_three.md` §5.2）。

**边界**：18 core 的更新规则（匹配毁灭、代权重 `gen_w`、$\alpha$、
$\gamma_{\rm gen}$、$\lambda_{\rm gen}$）都是建模选择；C3 手征是新输入；
$\alpha=0.3$、$\eta=0.2$ 是探索值，无标定；本稿不改变任何 Z 篇判定。
