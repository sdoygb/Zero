## §1 结构映射（提案，未验证）

把 Zero 的**已有结构**当成社会模型的“骨架”，不新造物理：

| 社会/政治/军事概念 | Zero 结构 | 可判据 |
|:--|:--|:--|
| 个体／行动者 | L2 走者（起点 $u$、当前位置 $w$） | 走者数、路径 |
| 行动 | 走一步（$W\leftarrow WA$） | 路径长度、闭合 |
| 合作／交换 | **闭合**（回到起点，$W_{uu}$） | 闭合率 |
| 冲突／背叛 | **终端层**（未闭合者被收走，$\tau$） | 终端通量 |
| 记忆／声誉 | L1 记录 $r_u$ | 记录分布 |
| 制度 | **稳定的闭合模式**＋保留规则（top2/last/cap） | 模式稳定性、寿命 |
| 权力／集中度 | 保留权重的 Gini／容量 | Gini、$q=\sum p^2$ |
| 信息不对称 | 局部边缘态不变（Z008 定理 20） | 单方可提取信息 |
| 历史 | L1 累积记录（不可逆） | 记录单调性 |
| 制度变迁 | 毁灭—重播种（$T=L$） | 周期、恢复时间 |
| 战略 | 保留规则/容量参数的选择 | 相图 |
| 战争 | 终端通量的爆发（容量越界） | 事件频率、规模分布 |
| 合法性 | 闭合模式的**自持**（不靠外部注入） | 无外力下的存活时间 |

**边界**：这是**类比映射**，不是“社会物理定律”；每条都要有可失败的反面对照（例如“改保留规则必须改变制度寿命”），否则就是比附。

## §2 最小模型（提案）

**舞台**：K4 或 Heawood（Zero 已有）。

**状态**：每个顶点一个走者群；每代走 $L$ 步；闭合 = 合作，未闭合 = 冲突（进终端层）。

**制度**：保留规则（top2/last/cap）作为“制度”；不同规则 = 不同制度。

**要测的四件事**：

1. **制度自持**：无外部注入时，某种保留规则能否让闭合模式存活超过 $10^3$ 代？
2. **权力集中**：保留权重的 Gini 随规则/容量的变化；
3. **冲击响应**：一次容量越界（战争/危机）后，恢复到原模式的时间；
4. **信息不对称**：一方改自己的状态，另一方局部可测量是否变化（应不变，Z008 定理 20）——这给“社会系统里的单方失明”一个代数判据。

**判据先写死**：每条都要有 **会失败的反面对照**（换规则必变、去掉闭合必崩、改一方对方局部不变），否则不写结论。
