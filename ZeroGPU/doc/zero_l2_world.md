# L2 哪个层是我们的世界：单槽 vs 整层的判别测试

**性质**：讨论稿，不占正式篇号，不改变根目录 Z 篇的任何判定。
**脚本**：`ZeroGPU/src/zero_l2_world_test.py`。
**数据**：`results/zero_l2_world_test.json`、`zero_l2_world_test.png`。
**复跑**：

```bash
cd ZeroGPU/src && /usr/bin/python3 zero_l2_world_test.py
```

---

## 摘要

问题：L2 的**某一个亚层**（f0/f1/f2）是我们的世界，还是**整个 L2** 才是？

$$
\boxed{\;
\text{整个 L2 是"我们的世界"的候选；单个亚层只是坐标/读出，不是世界。}
\;}
$$

三条判据：**自治**（有没有自己的更新律）、**承载**（能不能装下三代）、**选择**
（动力学是否选出某一个槽）。结果：

1. **单槽不自治**：AR(1) 自预测 $R^2=0.18/0.25/0.20$；驱动 $R^2=0.56/0.61/0.57$，
   驱动增量 $0.37/0.36/0.37$。三个槽都是**被驱动**的，没有自己的更新律。
2. **三槽是同一状态的三条坐标**：$p\to f$ 的 Jacobian 秩 $=3$（三槽承载 3 自由度）；
   两两相关 $0.84$–$0.97$——它们不是三个独立世界。
3. **整层有自己的更新律**：闭合律 $c_{t+1}=A^L c_t$ 精确（max rel dev
   $2.8\times10^{-16}$）。只有整个 L2 通过"自治"判据。
4. **没有特殊槽**：三个槽的均值/方差相近（$-0.05/-0.01/0.05$，
   $0.17/0.23/0.19$），动力学没有选出"最后一个"；唯一的序来自 seed（输入）。

**判定**：**"最后一个亚层 = 我们的世界"是标签约定，不是动力学事实。** 物理世界
对应的是**整个 L2 活动层**；三个亚层是它的三条坐标（对应"三代"的计数），不是三个
独立的世界。

---

## §1 判据

### 1.1 自治

Z016 的层纪律：只有 L2 有自身更新律；L0/L1 是结构/历史。若某个亚层是"世界"，
它至少应能**自己预测自己**（AR 自预测），而不是完全被别的量驱动。

### 1.2 承载

我们的世界至少要有"三代"（3 个自由度）。一个标量（单槽）只有 1 个自由度；
三个槽合起来才承载 $p\in\Delta^3$ 的 3 个自由度。

### 1.3 选择

若动力学真的选出某一个槽，三个槽的统计/响应应有一个是特殊的。若没有，则
"最后那个"只是排序约定。

---

## §2 结果

| 判据 | 单槽（f0/f1/f2） | 整层 L2 |
|:--|:--|:--|
| 自治（AR(1) $R^2$） | $0.18/0.25/0.20$ | **有更新律**（闭合律精确 $2.8\times10^{-16}$） |
| 被驱动（驱动 $R^2$） | $0.56/0.61/0.57$（增量 $0.37$） | — |
| 承载（自由度） | 1 | **3**（$p\to f$ 秩 3） |
| 选择（是否有特殊槽） | 无（两两相关 $0.84$–$0.97$，均值/方差相近） | — |

**读法**：

- 单槽像"温度计"：读数由环境（$Bd$）决定，自己不会动；三个读数之间高度相关，
  因为它们量的是同一个状态的不同侧面。
- 整层像"房间"：有墙（$\Gamma$）、有活动（走者/闭合/毁灭），才有自己的更新律。
  "温度计"不是"房间"。

---

## §3 判定

1. **整个 L2 是"我们的世界"的候选**：只有它通过自治判据；三个槽是它的三条坐标。
2. **单个亚层不是世界**：它没有自己的更新律，只承载 1 个自由度，且没有动力学
   选择它。
3. **"最后一个亚层 = 我们的世界"不成立**（作为动力学陈述）；作为**标签**可以
   ——把 seed 序里最轻的边界叫"我们的层"是一种命名约定，不是物理分离。
4. **三代**对应的是**三个槽的计数**（整层的 3 条坐标），不是三个独立世界。

---

## §4 边界与限定

1. **"世界"是层纪律的候选**，不是"L2 已经是完整力学"的证明；L2 仍然没有
   作用量/能量/连续时间（Z024／Z005），传统力学只能是它的有效描述。
2. **判据是动力学/信息判据**，不是测量判据；L2 的槽值没有被测量直接约束
   （Z161：3 槽是计数，不是质量数值）。
3. **$T=4$、容量阈值、$\alpha$ 都是引擎里的无量纲选择**，不是测量定的。
4. 不是 Z 篇。
