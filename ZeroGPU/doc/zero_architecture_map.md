## §2 这张图**不**画什么（有意省略，须一并说明）

1. **只画已证的结构性事实**。按库内体例（`_staging/文档纪律_正文不留工作痕迹.md`），正文只写**做过的、有正面结果的推导**；图上因此只出现已证结构与已算数字，不出现知识状态类表述。故 FRW、QFT 之门、共形因子等内容不在本图表达范围。
2. **不画宇宙学**。库里 Z029 的判定是：Zero 算得出「共有多少」，算不出「每单位多少」；$a(t)$ 与 $\rho(t)$ 都不存在。**所以这张图不是 FRW 宇宙学图**——若期望看到尺度因子／密度／Friedmann 方程，那不在本图的表达范围。
3. **不画数据诊断曲线**。既有 81 张 PNG 已经承担了那件事（$b_h$ 分布、3 槽动力学、脉冲响应、16/8/4 扫描等）；本图是**结构图**，不重复。
4. **不画标度链的四环细节**。$v\to M_Z\to M_I\to M_X^{\rm unif}\to M_X^{E6}$ 只在底部以锚点形式出现；四环（Z153–Z156）有各自专篇。

## §4 边界

1. 本图是**表达**，不是推导；图中不含任何新结论。所有内容均为既有篇目的**指针**。
2. 图把四层、六边、舞台、读出、物理量**排在同一张纸上**，是为了可读性；这不表示它们在同一层——**跨层拼接是被 Z016 禁止的**（层坍塌）。读图时每块仍须按其自身层指标理解。
3. 图上「物理量」一块里的 $D=4$、$\sin^2\theta_w=3/8$、$m_k=A^2M_k^2$ 分属不同轴（结构／高能角／质量），**不是同一个推导的连续输出**；$v$ 是唯一的量纲锚，属另一笔账。
