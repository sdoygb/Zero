### ① 中微子绝对质量

| 项 | 内容 |
|:--|:--|
| 公式 | $m_{\nu k}=A^2\bigl(\tfrac29\bigr)^{15}\bigl(0,\ 3-2\sqrt2,\ 1\bigr)_k$ |
| 结果 | $(0,\ 8.570,\ 49.951)$ meV，$\Sigma m_\nu=58.52$ meV |
| 位置 | **Zb031 §2**（定理 2.4） |
| 结构来源 | $15=16-1$（两条计数同给）；每步 $2/9=(2/3)(1/3)$ 来自 seed 的 $2:1$；$3-2\sqrt2=(\sqrt2-1)^2=\tan^2(\pi/8)$ |

| 与实验 | $\Delta m^2_{21}$ 比值 $0.975$；$\Delta m^2_{31}$ 比值 $1.018$；$m_2/m_3=3-2\sqrt2$ **精确**（非拟合） |
| 提交 | `4f73280` |

### ② Koide 公式推导

| 项 | 内容 |
|:--|:--|
| 形状 | $\mathbb Z_3$ 等变 ⟹ 厄米循环矩阵 ⟹ $\sqrt{m_n}=A[1+b\cos(\theta+2\pi(n-1)/3)]$（**导出**） |
| $Q$ 的公式 | $Q=(1+b^2/2)/3$（**代数**，用 $\sum\cos=0$、$\sum\cos^2=3/2$） |
| 振幅 | $b=\sqrt2$ 是**具名条件（C）**：块等功率 $\lvert\hat s_1\rvert^2/\hat s_0^2=\frac12$ |
| 结论 | $Q=\frac{1+2/2}{3}=\frac23$ **精确** |
| 位置 | **Zb041 §2.5**（定理 2.3／2.4／2.6） |
| 额外发现 | 补上了 $(2.5)$ 的**非负适用条件**：$\theta=60°$ 时公式失效（$Q$ 数值 $0.409$ vs 公式 $0.667$） |
| 提交 | `f01d0cc` |

**两条加起来的意义**：$Q=2/3$ 与中微子质量都不再是"经验公式"——它们各自接上了结构（$\mathbb Z_3$、$16-1$、$2:1$、$\sqrt2$）。
