## §1 四因子框架

质量律（Z121）：$m=A_s^2\,(1+A_s\cos\theta)^2$，三代按 $2\pi/3$。四个因子：

| 因子 | 内容 |
|:--|:--|
| (a) 相位 | $\theta$ 所在的格 $Z_{24}\cong Z_8\times Z_3$（闭合 8 分 × 代际 3 分，CRT） |
| (b) 振幅 | $A_s$（轻子 $\sqrt2$、中微子 $\sqrt7$、上型 $1.778$、下型 $2.683$） |
| (c) 单元 | $A_s^2$ 前的整体因子（轻子/下型 $A^2=v/784.5$；上型 $\approx72A^2$；中微子 $\sim1.6\times10^{-10}A^2$） |
| (d) 占据/通道 | 半槽 $1/2$、槽对子数 $56/784$ |

## §4 反例与负面结果

| 结论 | 证据 |
|:--|:--|
| 24 格不覆盖混合角 | $\theta_{12}/\theta_{23}/\theta_{13}$ 偏离 $4$–$50\sigma$；$\delta_{CP}$ 精度不足 |
| 上/下型不对称无态计数解释 | 两者色/自旋态数相同（$18$/$36$） |
| "换更细的格"不可检验 | 夸克相位在 $2\pi/24$ 偏离 $4.6°/5.3°$，$2\pi/48$ 偏离 $2.3$–$2.9°$，$2\pi/96$ 偏离 $0.9$–$1.5°$——格越细，任何连续相位都越"接近"格；$24$ 格是唯一由闭包**预先给定**的格，更细的格只是连续极限的逼近 |
| 行列式读法失败 | $S_4$ 正则表示上升算子谱 $\{\pm6,0^4,\pm2^9\}$，非标量、$\det=0$ |
| 时间型读法失败 | Z017：$T$ 是不动点参数；$\rho(T)$ 线性无常数项，不能唯一反解整数 |
| 双覆盖/$C_3$ 不产生 $5,79$ | 谱 $\{4,2,0,-2^3\}$、不变量 $\{|1-\omega|=\sqrt3,\dots\}$ |

## §6 要把 §3 变成 §2，需要什么

1. **$72$ 的结构**：一条把"色 $3$ × 相位格 $24$"与**上型专属**接起来的结论（下型为什么不带）；
2. **夸克振幅**：把 $79/25$、$36/5$ 写成计数/谱量，而不是"最简分数"；
3. **中微子单元拆分**：一条强制 $(1/56)^2(3/4)^{48}$ 的结构（不是数值拆分）；
4. **24 格的作用域**：为什么它只约束质量律相位、不约束混合角。

四条都属"新结构"，不是现有数值能判的。
