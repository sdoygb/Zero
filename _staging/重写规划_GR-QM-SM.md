## §0 目标与三条硬判据

**目标**：把 GR、QM、SM 三块基础写成**可独立阅读、证明完整**的篇；旧库它们分散在 172 篇里、且常以"判定篇"形式出现。

**判据**（写每一新篇时都必须满足）：

1. **一篇一对象**：一篇只立一个理论对象（如"度量与 Lovelock"），不把四段塞进一篇。
2. **证明完整**：篇内每条定理自成闭环。跨篇**只允许引定义与记号**，不允许写"证明见某篇"或"由前篇得"。
   （旧库 Z002 一条链跨 46 KB，读者要来回翻，这是要修的主要问题。）
3. **正文只写正面结果**：旧库大量"判死/不可能/被排除"的判定篇，其**否定结论**降为边界句或移入 `_staging/`；正面结论并入相应理论篇。

**编号政策（已定）**：**按写作顺序连续分配**，不预留号段。
理由：`zero_new_note` 按最大号 +1 配号，预留号段会制造空号，而空号在体检里要一路解释。
块归属写在本文与将来的 README 索引里，**不靠号段表达**。

写作顺序（已定）：**层与演化 → GR → QM → SM**。层块先写，所以它拿最靠前的号。
