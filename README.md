## 唯一公理

$$
\textbf{Z0（零不停留）}
\begin{cases}
\text{① 零不停留：零（平衡／闭合态）不是静止态，它持续运动；}\\
\text{② 从不停歇：运动不因任何时刻而终止；}\\
\text{③ 不设概率：运动不带权重——没有选择规则。}
\end{cases}
$$

**除 Z0 外无其它公理。**

## 怎么跑

**Python 侧**（数值／精确算术复算，逐条对应稿件里的定理）：

```bash
python3 check/03/QMR01_check.py        # 每个脚本自足，直接跑
```

**Lean 侧**（证明由内核逐行检查）：

```bash
export PATH="$HOME/.local/lean4/bin:$PATH"   # 工具链装在 ~/.local/lean4（官方 release，不需要 elan）
cd ZeroLean
lake build                                    # 全绿 = 所有定理被内核接受
python3 scripts/check.py                      # CI 守则（下面三条）
```

CI 三条守则（任一违反即非零退出）：

| # | 规则 |
|--:|:--|
| **R1** | 禁 `sorryAx`——证明里不许有洞 |
| **R2** | 公理白名单——除 Lean 基石公理（`propext`／`Classical.choice`／`Quot.sound`）与 `scripts/axioms-allow.txt` 里登记的 Zero 侧输入外，不许出现别的公有理 |
| **R3** | 定理名对得上篇号——形如 `zNNN_*` 的定理，`NNN` 必须是库里真实存在的 Z 篇 |

最近一次机器检查（本机重跑，2026-10-15）：`lake build: OK`，审计 `Zero.*` 定理 **797 条**（白名单 4 个名字／库内 133 篇），**守则全过**——无 `sorryAx`、无未登记公有理、定理名与篇号一致。机器可读记录见 [`ZeroLean/.lean-report.json`](ZeroLean/.lean-report.json)（2026-10-14 那一版同数）。

## 纪律

1. **根目录只放确认过的正式稿**：没有明确下令，不在根目录新开正式篇；讨论一律先进 `_staging/` 或 `ZeroGPU/`。
2. **暂存稿不占正式编号、不被正式篇引用**（唯一例外：核验脚本可被正式篇按路径引用，因为它可复跑）。
3. **落盘前跑一遍 LaTeX 五项检查**（数学块内不得有 Markdown 链接、行内 `$…$` 同理、逐块追踪括号深度、`\tag` 不重复不跳号、相对链接按稿件所在目录解析）。
4. **结论只写「判定 ＋ 指针」**：依据落到文档节／脚本／数字，不设两处真理源。
5. **正文不留工作痕迹**（[Z137](Z137_文档纪律：正文不留工作痕迹.md)）：正文只留两类内容——**已证的事实与证明**、**未证的开放项**。不写**版本比较**（已收窄／已被取代／已解决／不再承重）、不写**过程叙述**（本次修订／状态更新／第一版因…）、不写**内部台账**（登记表／归属表／闭合判据）。未证出的直接写"开放"。机检脚本：`_staging/style_check.py`。
6. **正文不引旧库**（[Z138](Z138_引用纪律：正文不引旧库.md)）：旧库的推导与结果**可以照用**，但正文里不得出现旧库／相邻项目的**编号、篇名、章节**，也不得用「旧库」当来源。结果**直接写成本篇的推导**（附证明或核验），或登记为**具名输入**。机检脚本：`_staging/oldcorpus_check.py`。
