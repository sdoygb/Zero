## 这是什么

Zero 把「零」立成一个可算的对象：

$$
\text{零}=\ker L,\qquad
\text{场}=(\ker L)^{\perp}=\Bigl\{x:\textstyle\sum_v x_v=0\Bigr\}.
$$

两条公理：

- **① 零不停留**：平衡态不是静止态，它持续运动；
- **② 不设概率**：运动不带权重——体系中不含选择规则。

「不终止」是定理，不是公理。库的工作是把这一框架下能严格推导的部分逐篇写清，并把每一笔输入按四类记账：**具名条件（C）／结构选择（I）／初值·边界／单位（锚）**。

**这不是同行评审出版物**，是一份可复算的研究记录。每篇的结论以该篇前言与正文定理为准；结论只写「判定 ＋ 指针」，依据落到本篇的节、脚本或数字。
