# Zero · 从单一公理推导物理

> 一个从**单一条公理**出发的离散物理推导项目。
> 本仓库是该推导链的**完整工作台账**：文档、核验脚本、否证记录与开放项。

---

## 唯一公理

$$
\boxed{
\textbf{Z0（零不断乱动）}
\begin{cases}
\text{① 零不停留：零（平衡／闭合态）不是静止态，它持续运动；}\\
\text{② 从不停歇：运动不因任何时刻而终止；}\\
\text{③ 不设概率：运动不带权重——没有选择规则。}
\end{cases}}
$$

**除 Z0 外无其它公理。** `Z1`–`Z5`（词与图、全分支＋整数重数、闭合与退出、寿命与终端、重播种）全部由它导出。

---

## 诚实的总判定

$$
\boxed{\ \textbf{当前进度是「条件恢复」，不是「无条件导出」。}\ }
$$

在 `Z0 + 识别 U + E1/E2/E3/E4 + 参数` 下，**条件推出**四维 GR 的结构、Lovelock 场方程、守恒源与有限前沿锥。

**不能主张**：从「零不断乱动」无条件、无输入地导出四维 GR。
**也不能主张**：量子力学、物质扇区、绝对标度已被导出。

## 核验

每个文档都配有独立核验脚本，退出码 `0` 表示全部断言通过。

```bash
# 单篇核验（示例）
python3 Z0_check.py
python3 R0_check.py
python3 STATUS_check.py

# 抽验若干
python3 LAYER_LEDGER_check.py
python3 E1_NN_check.py
```

**核验纪律**：数值核验只算旁证，不替代证明；每条结论必须带**层指标**（见 [`R95`](R95_layer_table_and_discipline.md) 的层表与 [`R50`](R50_layer_discipline.md) 的层纪律）。

## 分层结构（关键）

物理世界在 **L2**。同一个量在不同层表现**不一样**，比较前必须对齐层。

| 层 | 内容 | 有自身更新律？ | 是物理世界？ |
|:--|:--|:--|:--|
| **L0** | Z0 条款；整数重数；局域补偿移动 | 无 | ✗ |
| **L1** | 精确词（历史层） | 无（只增、不可逆） | ✗ |
| **L1′** | 全局闭合类层（记录与读出） | 无 | ✗ |
| **L2** | **演化层**（活动层） | **有** | ✅ |
