## 唯一公理

$$
\textbf{Z0（零不停留）}
\begin{cases}
\text{① 零不停留：零（平衡态、闭合态）不是静止态，它持续运动；}\\
\text{② 从不停歇：运动不因任何时刻而终止；}\\
\text{③ 不设概率：运动不带权重——体系中不含选择规则。}
\end{cases}
$$

**除 $Z_0$ 外无其它公理。** 三款各买回一件东西（符号结构／闭合约束／计数测度），其余结构均为导出（Z001 §2）。

## 怎么跑

**Lean 侧**（证明由内核逐行检查）：

```bash
export PATH="$HOME/.local/lean4/bin:$PATH"   # 工具链在 ~/.local/lean4（官方 release，不需要 elan）
cd ZeroLean
lake build                                   # 全绿 = 所有定理被内核接受
python3 scripts/check.py                     # CI 守则（下面三条）
```

**Python 侧**（数值／精确算术，逐条对应稿件里的定理）：

```bash
python3 ZeroGPU/src/zero_sim.py      # 公共核心自检：96 条判据 → results/zero_sim.json
python3 ZeroGPU/src/z0_engine.py     # 忠实动力学引擎自检：24 条断言
```

## 纪律

1. **根目录只放确认过的正式稿**：没有明确下令，不在根目录新开正式篇；讨论先进 `ZeroGPU/`。
2. **暂存稿不占正式编号、不被正式篇引用**（唯一例外：核验脚本可被正式篇按路径引用，因为它可复跑）。
3. **落盘前跑一遍 LaTeX 五项检查**（数学块内不得有 Markdown 链接；行内 `$…$` 同理；逐块追踪括号深度；`\tag` 不重复不跳号；相对链接按稿件所在目录解析）。
4. **结论只写「判定 ＋ 指针」**：依据落到文档节／脚本／数字，不设两处真理源。
5. **正文只写做过的、有正面结果的推导**：不写「否证／墙／不可能」这类断语；与已证定理连带、但未完整证明的写「开放」并点出背靠哪条定理；不写版本比较、过程叙述与内部台账。
6. **正文不引旧库**：旧库的推导与结果可以照用，但正文里不出现旧库的编号、篇名、章节，也不用「旧库」当来源；结果要么写成本篇的推导，要么登记为具名输入。
7. **量纲锚纪律**：整个架构只有一个量纲锚 $v$（电弱真空期望值）；一切有量纲量写成 $X=c_Xv^{n_X}$（$c_X$ 无量纲）。若推导链上出现两个可独立取值的有量纲常数，只能合并为同一 $v$ 的幂次，或把比值登记为无量纲输入。
